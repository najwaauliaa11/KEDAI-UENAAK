Website sederhana Kedai Uenaak untuk tugas UTS Pemrograman Web Dasar. Website ini menampilkan menu makanan dan minuman, informasi kedai, serta simulasi pemesanan.

Saya menggunakan HTML untuk struktur halaman, CSS untuk tampilan, warna, font, transisi, dan animasi dan JavaScript untuk membaca form dan menghitung pesanan.

## Halaman Website

- Beranda: sambutan dan menu favorit.
- Makanan: foto, deskripsi, dan harga makanan.
- Minuman: daftar minuman beserta harga.
- Pesanan: form pemesanan dan simulasi pembayaran.
- Lokasi: informasi lokasi kedai.
- Kontak: informasi kontak kedai.

Tampilan dibagi menggunakan frameset menjadi banner atas, navigasi di kiri, dan halaman isi di kanan.

## Fitur

- Memilih beberapa makanan dan minuman sekaligus.
- Menentukan jumlah setiap menu.
- Menghitung total harga pesanan.
- Memilih makan di tempat, bungkus, atau diantar.
- Mengisi alamat untuk pesanan diantar.
- Menambahkan catatan pesanan.
- Menampilkan ringkasan dan QR pembayaran.
- Menampilkan daftar bernomor, seperti Pesanan 1 dan Pesanan 2.
- Animasi masuk halaman dan efek hover pada menu, kartu, dan tombol.

## Cara Memesan

1. Buka halaman Pesanan.
2. Isi nama dan nomor telepon.
3. Isi jumlah makanan dan minuman yang dipilih.
4. Pilih jenis pesanan.
5. Jika memilih Diantar, isi alamat pengantaran.
6. Tambahkan catatan jika diperlukan.
7. Klik Lanjut ke Pembayaran.
8. Periksa ringkasan dan total harga.
9. Setelah melakukan pembayaran, klik Saya Sudah Membayar.
10. Pesanan akan muncul pada daftar pesanan.

## Catatan

Website ini merupakan simulasi untuk pembelajaran.

- Pesanan belum dikirim ke sistem kedai.
- Konfirmasi pembayaran berasal dari pemesan dan belum diverifikasi otomatis.
- QR pembayaran menggunakan gambar yang tersedia dalam proyek.
- Total harga menu belum termasuk ongkos antar.
- Penyimpanan riwayat bergantung pada versi JavaScript yang digunakan: sementara dalam variabel atau menggunakan localStorage.
